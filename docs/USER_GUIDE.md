# 智余 · 用户指南

菜单栏应用 · 无 Dock · macOS 15+

## 安装运行

从项目 GitHub Releases 下载 DMG（拖到“应用程序”）或 PKG 安装包；正式入口为 `/Applications/智余.app`。更新时替换应用本身，不需要删除 Application Support 设置目录。

开发构建方法见根目录 README；测试副本不要覆盖用户安装版。
菜单栏出现 **¥** /「智余」即可点开。

## 上手

### 1. 添加账号

**设置 → API 账号 → 点开平台**

| 平台 | 填写 |
|------|------|
| DeepSeek / OpenRouter / Kimi / ViralTok / 老张 | API Key 或系统令牌 |
| New-API | Base URL + 用户 ID + 系统访问令牌 |
| DMXAPI | 用户 ID + 系统访问令牌 |
| 火山引擎 | Access Key ID + Secret Access Key |
| 小米 MiMo / MiniMax / apinebula | 浏览器登录官网后点「自动连接并添加」，自动识别 Cookie 和 UID |
| Bytebroad | 浏览器登录 `token.bytebroad.com.cn` 后点「自动连接并添加」，查询人民币钱包，不是套餐额度 |

### 自动查找与重新连接

1. 已在 Chrome / Edge 登录？直接点「自动连接并添加」。软件自动查找可读的浏览器用户目录，识别当前平台会话和 UID，并先查询钱包；成功后才保存账号。
2. 如果提示未登录，点「打开官网登录」，自行在官网完成登录。
3. 回到智余，点「登录完成，重新连接」，自动获取数据；已有账号可直接点该行的「重新连接」，无需点钥匙图标或重复新增。

按钮下持续显示进度与结果；手动 Cookie 入口保留在折叠的高级选项中。导入或查询失败不清空草稿、不新增空账号、不替换原凭据。账号刷新失败仍保留上次余额和成功更新时间。

登录失效会在账号卡和余额卡提示；已启用且系统已授权 Mac 通知时，也会发送不含余额或账号资料的提醒，每次运行中同一账号恢复前最多一次。普通网络/解析失败不会要求重新登录。智余不会替你输入密码、自动登录、后台轮询浏览器或自动打开网站。

### 浏览器目录访问被拒绝

目录访问被拒绝不等于网站未登录。首次点击连接遇到权限不足，会打开系统文件夹选择窗口；取消后按钮显示「授权目录并重新连接」。确认 Chrome 数据目录 `~/Library/Application Support/Google/Chrome`，或其 `Default` / `Profile …` 用户目录；Edge 对应 `~/Library/Application Support/Microsoft Edge`。选定单个用户目录时只导入该用户的登录态，便于切换账号；同次运行优先记住所选目录，重启后可能需要再次选择。取消窗口不会改动账号。

这一步是对选定目录的明确授权，不需要给智余开启全盘访问权限，也不会修改浏览器文件。若仍无法读取，可手动填写当前平台的 Cookie。浏览器 Safe Storage 钥匙串访问与目录权限是两回事，系统可能单独要求允许读取；智余不会把浏览器凭据放入配置、日志或公开文件。

自 0.4.4 起，保存后会验证钥匙串能直接读回，并保存新的账号引用，避免只在当前会话成功。当前发行包仍为 ad-hoc 签名；升级后若旧凭据显示待补，请在新版本中重新连接或填写一次，不用删除账号。此版本不改变签名，也不承诺跨签名自动继承旧密钥。

回首页点 **刷新**。

### 2. 报警

**设置 → 报警通知**

- 打开 Mac 通知 / 邮件报警
- 邮件需配置 SMTP（建议 465 + TLS）
- 可用「测试」验证

阈值在 **后台同步** 中调整。

### 3. 刷新间隔

**设置 → 后台同步**：仅手动 / 5 / 10 / 15 / 30 分钟。

### 4. 置顶

点图钉打开常驻窗口，切换应用不会自动关闭。

### 5. 查看用量

首页底栏点 **用量**，选择 **天 / 周 / 月**，再用左右箭头查看历史周期。设置入口已移到首页右上角齿轮。

- “接口统计”：渠道返回累计消费，智余记录相邻成功刷新之间的正差值。
- “余额估算”：渠道只返回余额，智余把相邻成功刷新之间的余额下降估算为消费。
- 周和月视图提供按日柱图；点选或拖动图表可查看当天金额。
- 人民币、美元和其他单位分卡显示，不换汇、不合并总计。

首次成功刷新只建立基线，下一次成功刷新后才可能出现消费。充值、累计值重置、密钥或用户 ID 变化、单位或统计方式变化只会重建基线；智余退出或 Mac 休眠期间无法逐日采样，跨日差额会归入后一次刷新日期，并显示边界提示。历史保留 400 天。

## 数据位置

| 内容 | 路径 |
|------|------|
| 设置 | `~/Library/Application Support/SmartBalance/settings.json` |
| 密钥 | macOS Keychain（普通条目，启动即可读） |
| 用量历史 | `…/usage-history.json`（权限 0600，不含任何密钥或响应正文） |

## 隐私与安全

- 不要把 `settings.json`、Keychain 导出、`app.log` 或旧版备份文件上传到 Issue、聊天或公开网盘。
- API Key、Cookie、SMTP 密码和系统令牌不会写入用量历史；提交问题前请删除凭据、邮箱地址和原始响应。
- 新设置迁移包和本机备份不含密钥；旧版 v1 数据备份可能含明文密钥。恢复预览中明确确认后，智余才会把它们写入普通 Keychain，不会弹出生物识别/系统密码框，也不会删除原文件。需要迁移时先阅读仓库的 [数据与隐私说明](./DATA_AND_PRIVACY.md)。
- 智余源代码采用 [Apache License 2.0（Apache-2.0）](../LICENSE)；贡献或报告安全问题请阅读 [CONTRIBUTING.md](../CONTRIBUTING.md) 和 [SECURITY.md](../SECURITY.md)。

## FAQ

| 问题 | 处理 |
|------|------|
| 401 / 缺用户 ID | New-API、DMXAPI 必须填用户 ID；用**系统令牌**不是模型 sk- |
| 火山报错 | 检查 AK/SK 与账单查询权限 |
| SMTP 失败 | 用 465 TLS；暂不支持 587 |
| 无通知 | 系统设置 → 通知 → 智余 |
| 窗口尺寸乱跳 | 请使用当前版本（主页、用量与设置固定同宽高） |
| 用量页暂时为空 | 首次成功刷新只建立基线；再次成功刷新后才会记录差额 |
| 某天金额偏大 | 若跨日未刷新，整段差额会归到后一次刷新日期；页面会显示提示 |

更多维护者和开发者信息见 [架构说明](./ARCHITECTURE.md)、[Provider 开发指南](./PROVIDER_DEVELOPMENT.md) 和 [发布清单](./RELEASE_CHECKLIST.md)。
