# 智余 0.4.4 (build 88)

- **日期**：2026-10-09
- **标签**：`v0.4.4`

## 本次更新

- 修复 Chrome 导入权限被误报为未找到浏览器；导入按钮显示持续进度和准确结果。
- 权限不足时可通过系统窗口选择浏览器目录；取消和失败保留草稿及原账号。
- 修复重新导入当次成功、重启后凭据不可读：新引用保存、钥匙串读回验证和账号原子保存。
- 已验证 MiniMax / APINebula 人民币钱包导入、刷新及重启；398 项本地测试通过。
- 仍为 ad-hoc 签名；升级后若账号显示待补，在新版本重新导入或填写一次。不要求全盘访问。

## 安装包

| 文件 | 怎么用 |
|------|--------|
| **智余-0.4.4.dmg** / **SmartBalance-0.4.4.dmg** | 打开后把 App **拖到 Applications**（推荐） |

## 首次打开

若提示无法验证开发者：Control + 点击 → 打开。  
临时签名（ad-hoc）。其他 Mac 首次：右键 → 打开，或 系统设置 → 隐私与安全性 → 仍要打开。

## 系统

macOS 15.0 或更高。

## 更新

设置 → 软件更新 → 检查更新（GitHub Releases，优先下载 dmg/pkg）。
