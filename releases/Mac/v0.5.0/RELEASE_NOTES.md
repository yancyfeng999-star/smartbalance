# 智余 0.5.0 (build 89)

- **日期**：2026-10-21
- **标签**：`v0.5.0`

## 本次更新

新增 Bytebroad 人民币钱包监控和累计消费；浏览器自动查找登录态，支持打开官网登录后重新连接，无需手抄 Cookie/UID；区分目录权限、登录失效与查询失败，保留上次余额。继续使用原有 ad-hoc 签名。

## 安装包

| 文件 | 怎么用 |
|------|--------|
| **智余-0.5.0.dmg** / **SmartBalance-0.5.0.dmg** | 打开后把 App **拖到 Applications**（推荐） |
| **智余-0.5.0.pkg** / **SmartBalance-0.5.0.pkg** | 双击，按安装向导装到「应用程序」 |

## 首次打开

若提示无法验证开发者：Control + 点击 → 打开。  
临时签名（ad-hoc）。其他 Mac 首次：右键 → 打开，或 系统设置 → 隐私与安全性 → 仍要打开。

## 系统

macOS 15.0 或更高。

## 更新

设置 → 软件更新 → 检查更新（GitHub Releases，优先下载 dmg/pkg）。
